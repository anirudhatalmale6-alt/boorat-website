FAQ
Common Questions
What is an anti-detect browser?+
An anti-detect browser lets you create multiple browser profiles, each with a unique fingerprint. Every profile appears as a completely different device to websites, preventing cross-account detection and bans.
What fingerprints does BOORAT mask?+
Canvas, WebGL vendor/renderer, audio context, navigator properties, screen resolution, timezone, WebRTC IPs, plugins, and more. Each profile gets a unique combination that passes all detection tests.
Can I use my own proxies?+
Yes. BOORAT supports custom proxies in HTTP and SOCKS5 format. Assign unique proxies per profile, use the built-in proxy pool with auto-rotation, or connect without any proxy.
How many profiles can I create?+
Starter: 5,000 profiles. Pro: 20,000 profiles. Enterprise: up to 100,000 profiles. Each maintains its own cookies, local storage, and browser data independently.
Is there a free trial?+
Contact us for a trial license. We offer limited-time trial keys so you can test BOORAT fully before committing to a subscription plan.
What platforms are supported?+
BOORAT currently supports Windows 10 and Windows 11 (64-bit). Mac and Linux versions are planned for future releases.
