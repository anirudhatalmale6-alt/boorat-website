FAQ

Frequently Asked Questions

What is an anti-detect browser?
An anti-detect browser allows you to create multiple browser profiles, each with a unique browser fingerprint. This means each profile appears as a completely different device and user to websites, preventing cross-account detection and bans.
What fingerprint parameters does BOORAT mask?
BOORAT masks canvas fingerprint, WebGL vendor/renderer, audio context, navigator properties (hardware concurrency, device memory, platform, languages), screen resolution, timezone, WebRTC IPs, plugins, and more. Each profile gets a unique combination that passes detection tests.
Can I use my own proxies?
Yes. BOORAT supports custom proxies in HTTP and SOCKS5 format. You can assign a unique proxy to each profile, use the built-in proxy pool with auto-rotation, or connect without any proxy.
How many profiles can I create?
Depending on your plan: Starter supports 5,000 profiles, Pro supports 20,000, and Enterprise supports up to 100,000 browser profiles. Each profile maintains its own cookies, local storage, and browser data.
Is there a free trial?
Contact us for a trial license. We offer limited-time trial keys so you can test BOORAT before committing to a subscription plan.
What platforms does BOORAT support?
BOORAT currently supports Windows (64-bit). It runs on Windows 10 and Windows 11. Mac and Linux versions are planned for future releases.
